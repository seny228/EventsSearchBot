# Telegram Bot для поиска фильмов и квестов

## О проекте

Данный проект представляет собой Telegram-бота, разработанного на языке Python. Бот предназначен для автоматизированного поиска и отображения информации о фильмах и квестах.

Программа получает данные с сайтов с помощью парсинга и выводит информацию пользователю в удобном формате прямо внутри Telegram.

Проект был создан в учебных целях для изучения:
- Telegram API;
- языка программирования Python;
- парсинга сайтов;
- работы с JSON;
- обработки пользовательских запросов.

---

# Возможности бота

Бот поддерживает несколько основных функций:

- просмотр фильмов;
- просмотр квестов;
- получение информации с сайтов;
- отображение изображений;
- использование кнопок и меню;
- навигация внутри бота;
- сохранение данных в JSON.

---

# Главное меню

После запуска бота пользователю доступны следующие разделы:

- 🎯 Квесты
- 🌐 Квесты с сайта
- 🎬 Фильм
- 🌐 Сайты

Также реализованы дополнительные кнопки:

- ➡️ Ещё квест
- ➡️ Ещё фильм
- 🔙 Назад

---

# Используемые технологии

В проекте используются следующие технологии и библиотеки:

- Python
- pyTelegramBotAPI
- requests
- BeautifulSoup4
- JSON
- Telegram API

---

# Парсинг данных

Для получения информации используется технология парсинга сайтов.

Бот автоматически:
- отправляет HTTP-запрос;
- получает HTML-код страницы;
- анализирует структуру сайта;
- извлекает нужную информацию;
- отображает данные пользователю.

Для парсинга используются библиотеки:
- requests
- BeautifulSoup4

---

# Хранение данных

Для хранения информации о квестах используется файл `quests.json`.

Это позволяет:
- сохранять данные локально;
- ускорять работу программы;
- уменьшать количество запросов к сайтам.

---

# Обработка ошибок

В проекте реализована обработка ошибок:

- ошибки подключения;
- таймауты;
- ошибки парсинга.

Это обеспечивает более стабильную работу бота.
